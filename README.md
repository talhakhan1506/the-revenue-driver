# Revenue Driver 🚀
### Multi-Agent AI Marketing & Growth Suite

**Revenue Driver** is an autonomous multi-agent AI application designed to automate high-impact digital marketing workflows for businesses and startups. Powered by advanced LLM inference via the **Groq API** and built with **Python & Streamlit**, the platform deploys a specialized multi-agent swarm to execute complex marketing tasks in seconds.

---

## 🌟 Key Features

1. **Competitor SEO Analysis Agent:** Analyzes competitive landscapes, identifies high-value search intent keywords, and establishes structural content recommendations.
2. **Meta Ads Copywriting Agent:** Formulates targeted ad variations (compelling hooks, body copy, and optimized CTAs) tailored for maximum Click-Through Rates (CTR).
3. **30-Day Lifecycle Email Funnel Agent:** Constructs complete automated email sequences to nurture leads, drive engagement, and maximize conversions.
4. **Instant PDF & Text Export:** Built-in document generation using `fpdf2` allows users to export their complete generated growth strategy as a downloadable report instantly.
5. **Modern Dark-Mode UI:** Features a custom, high-contrast dark theme optimized for seamless user experience.

---

## 🛠️ Tech Stack & Architecture

* **Frontend & UI:** Streamlit (Python)
* **AI / LLM Engine:** Groq API (`openai/gpt-oss-120b`)
* **Agent Architecture:** Multi-Agent Swarm Logic
* **Document Generation:** `fpdf2`
* **Version Control & Hosting:** GitHub & Streamlit Community Cloud
